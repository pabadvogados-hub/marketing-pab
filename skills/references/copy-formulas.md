# Copy Formulas — Design Expert

## FÓRMULAS PARA SLIDE DE GANCHO (Slide 1 do carrossel)

### Fórmula da Dor
```
[Situação que gera frustração]?
[Validação da dor]
[O que você vai aprender aqui] ↓
```
Exemplo: "Seu empregador te demitiu sem justa causa? Você tem direito a muito mais do que te disseram. Veja o que a lei garante ↓"

### Fórmula do Número
```
[N] [benefícios/direitos/erros] que
[público-alvo] [desconhece/ignora/perde]
Arraste para ver →
```
Exemplo: "7 direitos do motorista CLT que a empresa nunca vai te contar. Arraste →"

### Fórmula da Pergunta Direta
```
Você sabia que [fato surpreendente]?
Se não, esse post é pra você. →
```

### Fórmula do Desafio
```
[Afirmação controversa ou contraintuitiva]
[Por que isso importa para você]
Explico em [N] pontos →
```

## FÓRMULAS PARA SLIDES DE CONTEÚDO

### Estrutura "Ponto + Prova + Impacto"
```
[NÚMERO] [TÍTULO DO PONTO]
─────────────────────
[Explicação em 1-2 frases]
→ Na prática: [exemplo concreto]
```

### Estrutura "Lei + Tradução"
```
O que a lei diz:
"[Artigo ou norma simplificada]"

O que isso significa pra você:
[Explicação em linguagem simples]
```

### Estrutura "Mito vs Verdade"
```
✗ MITO: [crença errada comum]
✓ VERDADE: [o que realmente é]

[Consequência prática]
```

## VOCABULÁRIO POR PÚBLICO

### Para Caminhoneiros
**Use**: jornada, direitos, CLT, EPI, descanso, justa causa, horas extras, FGTS, viagem, frete, TAC, ANTT  
**Evite**: linguagem muito técnica, termos em latim, siglas sem explicação

### Para Empresários
**Use**: passivo trabalhista, risco jurídico, conformidade, gestão, compliance, custo por colaborador, ROI  
**Evite**: linguagem de "sindicato", tom confrontador, jargão de empregado

### Para Posts Institucionais
**Use**: excelência, inovação, resultado, estratégia, compromisso, expertise  
**Evite**: superlativos vazios ("o melhor", "número 1"), promessas sem base

## REGRAS DE COPYWRITING VISUAL

1. **Máximo 7 palavras** no título principal de qualquer slide
2. **Máximo 3 pontos** por slide de lista
3. **Uma ideia por slide** — se precisar de mais, adicione slide
4. **Números específicos** sempre que possível (7 direitos, não "vários")
5. **Verbos de ação** no CTA (Salve, Fale, Agende, Clique)
6. **Voz ativa** sempre — "A empresa deve pagar" não "Deve ser pago"
