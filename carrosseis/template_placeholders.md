# Template Master - Placeholders

Ao criar o template no Canva, use EXATAMENTE estes textos como placeholder.
O robo vai substituir cada um automaticamente.

---

## REGRAS VISUAIS (aplicar no Canva)

- **Header em TODOS os slides:** "WEVERTON & PAMELLA" (top-left) | "@wpcasalda.ia" (top-right) - cinza discreto
- **Barra de progresso dourada** no rodape de cada slide
- **Contador:** 1/7, 2/7... no canto inferior direito
- **Cor dourada:** #C8A84E (para labels e palavras destaque)
- **Fundo escuro:** #1A1A0F (slides 1, 2, 4, 5) - texto branco
- **Fundo claro:** #F5F0E8 (slides 3, 6, 7) - texto preto
- **Tipografia headlines:** Ultra bold, uppercase, condensed
- **Labels:** Uppercase, espaçadas, fonte pequena, dourado
- **Muito espaço negativo** no topo (conteudo na metade inferior)

## COMO CRIAR O TEMPLATE

1. Abra o Canva > Criar design > Post Instagram (1080x1080)
2. Crie 7 paginas seguindo o layout acima
3. Digite os placeholders EXATAMENTE como {{NOME}} nos campos de texto
4. Estilize tudo (fontes, cores, cards, espaçamentos)
5. Anote o ID do design (esta na URL: canva.com/design/XXXXXXXXXXX/...)
6. Me passe o ID e o robo faz o resto!
